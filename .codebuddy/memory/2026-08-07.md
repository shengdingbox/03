## PyInstaller 打包体积优化（200MB → 27MB）

优化历程：
1. **改用 `.spec` 文件**（命令行 `--exclude-module` 参数太长被截断未生效）
2. **自定义 `_collect_pyside6_binaries()`**：手动白名单过滤 Qt DLL，仅保留 QtCore/QtGui/QtWidgets/QtNetwork 四个模块 + 必要插件
3. **自定义 PySide6 hook**（`hooks/hook-PySide6.py` 等）：覆盖 PyInstaller 内置 hook，阻止 `collect_extra_binaries()` 自动收集不需要的 Qt DLL（Qt6Pdf、Qt6Qml、Qt6Quick 等）
4. **UPX 压缩**：下载 upx.exe 到 `tools/`，在 spec 中启用 `upx=True`，build.bat 中将 tools 加入 PATH
5. **排除不需要的 Python 包**：`setuptools`、`pip`、`wheel`、`pkg_resources`、`lib2to3`
6. **移除不需要的 Qt 插件**：SVG、GIF、JPEG、OpenSSL backend（Windows 用 Schannel）

最终体积：**27MB**（从 200+MB 降低 86%）

关键发现：
- PyInstaller 内置 `hook-PySide6.py` 调用 `pyside6_library_info.collect_extra_binaries()` 会全量收集 Qt 二进制，即使 spec 中自定义了 binaries 也无法阻止
- 解决方案：用 `hookspath` 指向自定义 hook 目录，覆盖内置 hook，将 `binaries = []`
- UPX 对启用 CFG (Control Flow Guard) 的 DLL 无法压缩，Qt6 核心 DLL 大多被跳过
- `importlib.import_module('src.main')` 动态导入需在 hiddenimports 中显式列出所有 src 子模块

## 修复 PyInstaller 打包后 ModuleNotFoundError: No module named 'src.main'

- **原因**：`app.py` 使用 `importlib.import_module('src.main')` 动态导入，PyInstaller 静态分析无法发现 `src` 包。
- **修复**：在 `BuddyToolNew.spec` 中：
  1. `pathex` 设为项目根目录
  2. `hiddenimports` 显式列出 `src` 及所有子模块（main/cli/main_window/modules.*/ui.*/utils.*/i18n.*/models.*）
